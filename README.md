## Features

-  **3 tarefas fixas** para reduzir overload e manter clareza.
-  **Tags** para direcionar o foco da sessão.
-  **Ruído marrom** (sim, somente um som).


## Rodando localmente

```sh
python3 -m http.server 8000
```

Abra: `http://localhost:8000`
